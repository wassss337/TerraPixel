# TerrariaMini

2D-песочница-выживание в духе Terraria, написанная на чистой Java (Swing/AWT)
без внешних библиотек. Все текстуры, звуки и музыка генерируются кодом в рантайме.

![screenshot](docs/screenshot.png)

## Возможности

- 🌍 Процедурная генерация мира 800×200 с биомами, пещерами, рудами и деревнями
- ⛏️ Добыча блоков, крафт, верстаки, печи, сундуки
- ⚔️ Инструменты 4 уровней (дерево/камень/железо/алмаз), монстры, урон от падения
- 🧑🌾 NPC-жители, достижения, система опыта
- 🌐 Мультиплеер по LAN (хост/клиент)
- 🎵 Процедурная музыка и звуки без единого аудиофайла
- 💾 Сохранение миров в файлы
